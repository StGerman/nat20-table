# The compass of the current world

The 9x9 grid of the compass rules in `commandments.md`, drawn for the current world (Wend), as text. It is world-specific, like `examples.md`, and is replaced with the world. Source: the producer's grid drawing `factions-compass-9x9` of 2026-11-07, which the bible's Why tab shows as a picture.

Columns C1 to C9 run from Custom (left) to Market (right). Rows 1 to 9 run from Tribute (top) to Freedom (bottom). Each 3x3 block is one region of the meme. Cells with no outline are ideas nobody in this world holds yet. There is no safe zone: each faction draws its own.
