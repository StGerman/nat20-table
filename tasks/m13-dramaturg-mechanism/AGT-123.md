The card bench command (decision 0084; `docs/design/card-bench.md` §3, §4, §6 item 1): `npm run play:card` copies the pack and its world into a temporary folder and takes every other card out of the copy's decks, the world's and the pack's, except a card the benched card's own choices add, so a pile of one puts it on the table with no draw-three and no pick; it cuts the copy's `world.start` and `world.route` to the shortest stretch that reaches the card (start at the last place on the pack's route that has a scene, before the card's road or place); it plays the real loop with the live DM, scripted AI seats that vote for the own move, and the caravan-moving scripted seat, moved from a helper in `game/test/campaign-loop.test.ts` to `game/src/table/scripted.ts`, which moves the caravan on until the card is on the table and then types the lines. Flags: `--card`; `--lines FILE`, one line of the player's words a row (`--seat ink` lets a person type instead); `--roster NAME`, played on a copy in a temporary `--rosters` folder so the saved party is never written over. Every bench run starts from a fresh copy of the pack and of the roster, so a `once` card decided in one run is there in the next. A line that settles the card ends the bench run and the next line starts a fresh one; when the lines run out with the card still waiting, the bench stops and never picks a number. The run driver's guard ("scripted players never move the caravan") stays for every other command, and `play:card` passes it. Where a deck check objects to a copy, the copy keeps the card it needs in a zone the cut route does not cross (§8). Out: night cards and chained cards (§3). Test with no model, in CI: for each campaign pack and every road and arrival card its route reaches that is not chained and reads no deed, with a scripted DM, the copy loads and that card is the first card on the table; and one card that reads a deed, played on a roster a scripted contract saves in the same test (on main, for one, `toll_man_stocks` in `worlds/wend/deck/wendford.json`, `if: toll_men_spared`, written in `millbeck.json`). No contract change, no engine change, no new player-facing text (§6)
