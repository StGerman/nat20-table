The roll audit is the talk's strongest claim (every roll the table speaks of was made and settled by the engine, Rule 4), but a run shows it as one line in `audit.json` ("55 engine rolls, 55 cited, 0 problems"). Done means: `npm run audit:show -- <run-dir> [--roll rN] [--limit N]` prints, for each roll the transcript cites, the line the table heard, the engine's own log entry for that roll (roller, check, dice, modifiers, total, target, outcome, log seq), whether the two agree, and the first DM narration after it; a header with the run's seed, build and the audit's verdict; read-only, no model, no engine. Tested on a committed fixture run folder.
