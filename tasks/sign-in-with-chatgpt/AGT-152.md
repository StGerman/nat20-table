The tunable text of the Narrator and player prompts (craft, voice, the lines each model needs, such as terra's hedge line) moves out of `dm.ts` and `player.ts` into files, `game/prompts/<provider>/`, over a shared base; the logic that picks parts (a human at the table or not, language, voice) stays in code, because Langfuse prompts take plain `{{variables}}` and no conditions. `npm run prompts:pull` writes the files from Langfuse prompts with a label and records each prompt's Langfuse version in the file. A run reads the files only. In a bench run on Stas's Mac, `PROMPTS=langfuse:<label>` fetches the labelled versions live, so a prompt can be tried without a code change. Every traced generation links its prompt name and version, so Langfuse shows the judge's scores per version. Done means a bench run with `PROMPTS=langfuse:staging` and a run from the files trace the same prompt version, and the scripted scene is unchanged.
