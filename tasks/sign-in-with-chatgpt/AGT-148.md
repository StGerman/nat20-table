The table's sign-in adapter behind `status()` and `signIn()` (Glass Table design §6), for the open-source SIWC flow: authorize at `auth.openai.com/api/accounts/authorize` with `client_id=dynamic_agent_client`, `agent_name_hint` and `ext_agent_host_id` on first sign-in and the issued `oaiapp_` id after; PKCE S256; callback on `http://127.0.0.1:<port>/auth/callback`; code exchange and rotating refresh at `/oauth/token` with `resource=https://api.openai.com/v1`; token file at 0600 in the app's data folder, never logged; sign-out by revocation. Done means scope §4 row 1 passes against a recorded fake auth server, the host id and sign-out revocation included. It replaces Glass Table's Claude sign-in adapter (AGT-144).
