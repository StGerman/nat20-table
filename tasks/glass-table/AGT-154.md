SwiftUI shell design §4 PR 4, §2 (seat), §3, decision 0093. Today `WebSeat` listens on 127.0.0.1 only, so a phone cannot sit down. Done means:
- `WebSeat` takes the address it listens on; on the loopback address nothing changes. `--seat-lan` on the play commands opens it to the home network and prints the link with its token. Off the loopback address no browser origin is let in, only a client that holds the token.
- **Two windows fight for the seat (design §5).** The seat closes the window it replaces with a WebSocket close code that says so, and that window stops asking for the seat. No wire message is added.
- While a seat is on the network, the host keeps the Mac awake (design §3, "The table waits for a phone that sleeps").

The spike's `web-seat.ts`, `driver.ts` and `settings.ts` changes (table #480) are the start, reviewed.
