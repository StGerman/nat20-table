# Lore

Setting text of our own, kept apart from rules content. A scenario pack lists the lore files its DM reads in `adventure.json` (`lore`), by a path relative to the pack, so several packs can share one setting.

Lore is DM context, like a pack's prose: it never goes into a player agent's prompt (Rule 3). What the characters know of the world, the DM tells them, and a personality card may say it in the character's own terms.

Each file says in its first lines what it covers and which packs it was written for.
